# Simple Kanban Board

A simple and interactive Kanban Board built using HTML, CSS, and JavaScript.

This project allows users to create tasks, move them between different lists using drag and drop, and delete tasks when they are no longer needed.

## Features

- Add new tasks
- Delete tasks
- Drag and drop tasks between lists
- Three task lists:
  - To Do
  - In Progress
  - Done
- Simple and clean user interface
- Responsive layout

## How It Works

### Add a Task

Type a task into the input field and click the **Add Task** button.

The new task will automatically be added to the **To Do** list.

### Delete a Task

Each task has a **Delete** button. Clicking the button removes the task from the board.

### Drag and Drop

Tasks can be dragged from one list to another.

For example:

```text
To Do → In Progress → Done
